طريقة الرفع الصحيحة إلى GitHub Pages

1) فك ضغط ملف alkhibra-v10-github-ready.zip على جهازك.
2) افتح المجلد الناتج، ولا ترفع ملف ZIP نفسه.
3) في مستودع GitHub افتح Add file ثم Upload files.
4) ارفع أولاً جميع الملفات الموجودة في جذر المجلد (ملفات HTML وCSS وJS وsitemap وغيرها).
5) بعد ذلك افتح مجلد assets داخل GitHub وارفع محتويات مجلد assets من جهازك مع الحفاظ على المجلدات الفرعية.
6) اضغط Commit changes.
7) انتظر 2 إلى 5 دقائق ثم افتح الموقع واضغط Ctrl + F5.

مهم: يجب أن يكون index.html في جذر المستودع مباشرة، وليس داخل مجلد إضافي.
